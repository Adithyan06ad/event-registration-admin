# Event Registration Admin Panel

## Project Overview
The Event Registration Admin Panel is a web application built using the MERN stack. It allows users to manage event information through a simple dashboard.

## Technologies Used
- **Frontend:** React.js, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **API:** REST API with Axios

## Features
- View all events in a dashboard
- Add new events
- Edit existing event details
- Delete events
- Search events by name
- View total registrations
- Responsive user interface

## Project Structure
- `frontend/` – React application
- `backend/` – Express server and API routes
- MongoDB Atlas – Database

## How to Run

### 1. Start the backend
Open a terminal in the backend folder:

```bash
npm install
node server.js
```

Configure the MongoDB connection string and port in `backend/.env`.

### 2. Start the frontend
Open another terminal in the frontend folder:

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.
